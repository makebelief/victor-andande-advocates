# Victor L. Andande & Co. Advocates

Production website for Victor L. Andande & Co. Advocates, Embu, Kenya.

## Local development

```bash
npm install
npm run dev
```

## Structure

- Static, multi-page HTML/CSS/JavaScript site
- Locally served, optimised official brand imagery and licensed editorial photography
- Static legal guides with no external CMS dependency
- Vercel clean URLs, cache controls and security headers
- Sitemap, robots, web manifest and branded error pages

The enquiry form prepares an email in the visitor's own email application. It does not transmit or store form submissions on the website.
